# Damascus Reign — notes for Claude

Web CLI roguelite RPG. **Zero-build, vanilla ES modules.** No npm, no framework,
no backend. Runs only over HTTP (ES modules can't load via `file://`).

## Run / test
```bash
python3 -m http.server 8080   # then open http://localhost:8080
```
There is no test suite. Verify changes by driving the game in a browser: the
game instance isn't global, so simulate input by setting `#cmd-input`'s value and
dispatching a `keydown` Enter event, then read `#output`/`#stats-content`.

## Layout
- `data/*.json` — all content (zones, monsters, item word-banks, rarities,
  affixes, classes, events, shop, forge, difficulties, skills, version).
  **Prefer editing data over code.**
- `src/engine/` — rng, data loader, Player state, command registry.
- `src/systems/` — items (procedural gen), classes, combat, forge, enchant,
  shop, encounters, skills, ai (optional BYO-key narrator), save.
- `src/ui/` — terminal, panels, render helpers.
- `src/main.js` — `Game` orchestrator: state machine
  (`MENU → IDLE → COMBAT / ENCOUNTER / BUSY / SKILLS`) + all command wiring.

## Conventions (extra)
- Skills: `player.skills` (ids) + `player.skillPoints` are the source of truth;
  `applySkillMods(player, data)` re-aggregates `player.skillMods` (consumed in
  `recalc()`). Call it after load/unlock. 1 point per level.
- Difficulty/hardcore are locked at creation. `Game.diffMods()` returns the
  combined mob/loot/xp/gold multipliers; applied in `makeEnemy`, rewards, drops.
- **Bump `data/version.json` `version` on every deploy** — the `update` command
  and outdated-client nudge depend on it.

## Conventions
- Items: generated by `systems/items.js`. An item stores raw rolls (`base`,
  `affixes`, `enhance`) and derives `.stats` via `computeStats()` — always
  recompute after changing enhancement/affixes, then call `player.recalc()`.
- Rarity tiers (rare→common cap): `F E D C B A S SS SSS X`. Affix count and stat
  multiplier come from `data/loot.json`.
- All randomness goes through the injected `RNG` (`src/engine/rng.js`) — don't
  call `Math.random()` directly in game logic.
- Saves: localStorage key `damascus_reign_saves_v2`; only raw Player JSON is
  stored (`SAVE_VERSION` in `state.js`). Derived stats recompute on load.
- AI: flavor-text only, never mechanics. Config in localStorage; degrades to
  procedural text on any failure.
